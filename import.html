Account-backed storage. Parsed, masked transaction data is stored in your Supabase account so it remains available after you close the browser. Access is restricted to your signed-in user through database Row Level Security.
Supported statement formats

PDF statements from supported bank layouts can be read directly, including image-only PDFs using on-device OCR. Spreadsheet imports look for columns such as Transaction Date, Description, Debit Amount, Credit Amount, Currency, and Statement Code.
